# TOMST DATA LIST
`Allyears_TOMST_Fieldnotes.csv`: A csv for tracking field notes about each TOMST after the end of the field season. Meant to be read by humans. 

`TOMST_metadata.csv`: Created in 2022 when the TOMST were first deployed. Includes information such as their first deployment date, location, site description, lat, long, and elevation. 

`TOMST_terrain.csv`: Derived from the Arctic DEM, this includes some slope, aspect, and elevation data for each TOMST site. 

`device_deployment_periods.csv`: Important dataset which includes dates that TOMST were deployed, last downloaded before death, and replaced, allowing for the creation of a continuous data set where multiple sensors are linked in a single location.
